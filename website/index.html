MADE FOR THE CLASSICS

Old software.
New possibilities.

DOSVBox builds on DOSBox Staging's modern emulation work. The aim is simple: make classic DOS software straightforward to run on current hardware.

▦
01 / DISPLAY

Graphics that feel right

From classic CGA and EGA to VGA and SVGA, the underlying emulator supports the display modes and scaling options that made the era distinctive.

♫
02 / AUDIO

Hear the difference

Support for classic PC audio hardware, MIDI synthesis and a range of sound devices through the DOSBox Staging foundation.

⌁
03 / COMPATIBILITY

Built for today's PCs

A modern C++ codebase and current build tooling help bring a decades-old software environment to modern operating systems.

x86x64ARM
⌘
04 / CONTROL

Your setup, your way

Keep game files organised, use familiar DOS commands, and customise emulator settings when a title needs extra attention.

PLAY SMART

Classic software.
Modern caution.

DOSVBox includes practical guidance for running old and untrusted DOS programs more safely. Use a dedicated games folder, avoid running as administrator, and only mount the directories you need.

Read the security guide ↗
01Run as a standard user ✓
02Mount only game folders ✓

DOSVBox is not an OS-level sandbox. Emulated programs run with the permissions of the DOSVBox process.
UP AND RUNNING

Three steps back
to the DOS prompt.

Get the application, keep your game files in one place, and start a session. Exact setup can vary by game.

01

Get DOSVBox

Open the v0.1.0 GitHub release and download the Windows installer when the build asset is available.

View release ↗
02

Make a games folder

Create a dedicated folder for your DOS games. Keep it separate from documents and personal files.

C:\DOSGames
03

Mount and play

Mount the folder inside DOSVBox, switch to the game directory, and run its executable.

mount c C:\DOSGames
